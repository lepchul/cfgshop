# КФГ ОТ МУХАМЕДА

Готовый проект Telegram-магазина конфигов. Python 3.11 или новее, без сторонних библиотек. Сам бот еще не создан в Telegram и не запущен: для этого нужен твой токен.

## Быстрый запуск на Windows

1. Создай бота через https://t.me/BotFather командой `/newbot`.
2. Укажи название `КФГ ОТ МУХАМЕДА`. Username выбери свободный, с окончанием `bot`.
3. Установи Python 3.11 или новее.
4. Скопируй `.env.example` в `.env`. Включи отображение расширений файлов, чтобы не получить `.env.txt`.
5. Заполни `BOT_TOKEN`, `ADMIN_IDS` и `SUPPORT_CONTACT`. В `ADMIN_IDS` нужны числовые Telegram ID, через запятую, без @. Если свой ID неизвестен, сначала поставь временное положительное число, запусти бота, отправь `/id`, затем впиши свой ID и перезапусти.
6. Запусти `start.bat` или `python bot.py` в папке проекта.
7. Открой бота, отправь `/start`, затем `/admin`.

Токен хранится только у тебя. Не публикуй `.env` и не отправляй его покупателям.

## Linux и работа круглосуточно

Запуск вручную: `python3 bot.py`.

С Docker: заполни `.env`, затем выполни `docker compose up -d --build`.
Остановка: `docker compose down`. Не добавляй `-v`: этот флаг удалит данные магазина.
Логи: `docker compose logs -f`.

Нужен постоянно работающий компьютер или сервер с доступом к api.telegram.org. Домен и открытые входящие порты не нужны. Запускай только один экземпляр бота с одним токеном. Если раньше использовался webhook, отключи его в прежнем приложении перед запуском.

## Как добавлять товары

В `/admin` нажми «Добавить товар». Бот по очереди попросит:

1. Название, до 32 символов.
2. Описание, до 650 символов. Укажи версию Standoff, устройство и совместимость.
3. Цену целым числом от 1 до 1000 Stars.
4. Картинку, отправленную как фото.
5. Файл конфига, отправленный как документ, до 49 МБ.
6. Инструкцию, до 3500 символов.

После инструкции товар сразу появится в магазине. `/cancel` отменяет ввод. Файлы и изображения сохраняются как Telegram file_id, база содержит ссылки на них. Не меняй бота на другой токен от другого бота: старые file_id для другого бота не подходят.

В «Товары» можно скрыть и вернуть товар. Для изменения содержимого создай новый товар и скрой прежний. У уже созданного заказа сохраняется исходный файл, инструкция и цена. Скрытие товара не отбирает оплаченные покупки.

## Оплата и выдача

Внутреннего баланса нет. Кнопка покупки создает персональный счет в XTR, с одной ценой. Неоплаченный счет принимается в течение часа, пока товар в продаже. Бот проверяет покупателя, сумму и валюту на pre-checkout. Выдача начинается только после successful_payment.

Платежи и очередь выдачи сохраняются в SQLite. Повторное событие с тем же ID платежа не создает новую покупку. При сбое отправки бот повторяет выдачу через минуту. После остановки и запуска очередь продолжается. В редком случае обрыва после успешной отправки, но до записи результата, файл может прийти еще раз. Повторного списания при этом нет.

«Мои покупки» позволяет скачать файл снова. Для поддержки есть `/paysupport`, для номеров последних 10 покупок `/receipt`. Возврат: `/admin` → «Возврат оплаты» → ID заказа → подтверждение суммы. После возврата повторное скачивание отключается, скачанный файл удалить с устройства покупателя невозможно.

Платеж с неожиданной суммой, владельцем или повторной оплатой уже оплаченного заказа сохраняется в `payment_events` со статусом `needs_review`, без автоматической выдачи. Администратор получает уведомление. Такие события нужно проверить и при необходимости вернуть через официальный refundStarPayment, используя сохраненные uid и telegram_payment_charge_id. Не удаляй их из базы до разбирательства.

## Отзывы

Отзывы только после оплаты, от 1 до 5 звезд. Один отзыв на пользователя и товар, повторное заполнение обновляет его. Можно выбрать собственное имя или «Аноним». Telegram username не запрашивается и не сохраняется. @упоминания и ссылки в тексте скрываются. Обычный текст, похожий на ник без @, технически неотличим от выбранного имени.

Анонимность действует для посетителей. В базе есть Telegram ID автора, чтобы подтвердить покупку. Администратор может скрывать и возвращать настоящие отзывы. Поддельных отзывов и накрутки нет. Скрытый модератором отзыв не становится видимым при редактировании покупателем. Отзыв после возврата скрывается, если других действующих покупок этого товара нет.

## Данные и обслуживание

Сохраняй резервную копию всего каталога `data` при остановленном боте, либо используй SQLite backup API. Для Docker данные находятся в томе `shop_data`. В базе есть ID покупателей, покупки, платежные ID, товары, отзывы и незавершенные шаги диалогов. Доступ к серверу и копиям должен быть только у владельца.

`SUPPORT_CONTACT` укажи реальный. В `SHOP_TERMS` допиши свои условия поддержки, совместимости и возвратов. Встроенные `/terms` и `/privacy` показывают покупателю условия и описание хранимых данных.

Проверки без токена: `python -m unittest -v`.
В комплекте тесты прав администратора, границ цены, проверки счета, сохранения платежа, повторной выдачи, повторных событий, возвратов и отзывов.

Перед продажами проведи полный пробный заказ в тестовой среде Telegram или собственную покупку за 1 Star и возврат. В этой сборке проверены локальные сценарии с имитацией API. Реальные запросы Telegram и реальное списание без токена не проверялись.

Документация оплаты: https://core.telegram.org/bots/payments-stars
Bot API: https://core.telegram.org/bots/api
